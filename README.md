# PSC 프리체크
1. 이 폴더를 통째로 보관하고 `index.html`을 브라우저에서 엽니다(file:// 지원).
2. 체크리스트 만들기 → 샘플 보고서 → 자동으로 채우기·제출 → 시정 완료·보고서 순서로 진행합니다.
3. 마지막 화면의 링크 또는 `full.html`을 열면 전문가용 대시보드를 볼 수 있습니다.

## 모의 처리 범위
가상 선박 3척, 가상 Form B 보고서 1건과 준비된 분석 결과를 사용합니다. 실제 LLM·PDF 분석·사진 촬영·외부 전송은 없습니다. 사진 버튼과 시정 완료는 모의 처리입니다. 자가점검·언어·시정 상태는 localStorage에 저장하며 사용이 제한되면 메모리 상태로 동작합니다. 누락된 ISM 증빙은 자가점검 시정과 별도로 보고서에 남깁니다. 미지원 번역은 영어로 표시합니다. 통계 기반 점수는 검사 결과를 예측하지 않습니다.

## 데이터 출처
Tokyo MOU Annual Report 2025, NIR Information Sheet 2025-07, Tokyo MOU·Paris MOU CIC 2026 보도자료 수치를 수록했습니다. 원문 웹 자료의 별도 검증은 수행하지 않았습니다. CIC 설문은 영문 요지와 한국어이며 정식 검사 양식을 대체하지 않습니다. 범주별 비중 중 비상설비·추진기관은 총 90,168건으로 나눈 반올림 값입니다.

## 시험
```sh
PW_ROOT="<playwright 가 설치된 폴더>" node test-web.mjs
# URL 또는 파일 경로를 마지막 인자로 줄 수 있습니다.
```
Playwright는 worker에서 불러오며 이 폴더에 의존성을 설치하지 않습니다. 1280×800·390×844의 전체 흐름, 제출 조건, 증빙 누락, 해시·이력·pageshow, 저장 공유, 넘침, 외부 요청, 콘솔 오류를 확인합니다.

시험 결과(2026-10-18, macOS·Chromium headless, file:// 로컬): 데스크톱 1280×800·모바일 390×844 각 21항목, 42 PASS / 0 FAIL. 시연 범위: 위험도 가중점은 선종·선령만 계산하고 기국·선급·회사 성능은 샘플 값으로 고정합니다. 집중점검 가점은 입항일이 CIC 기간(2026-09-01~11-30) 안일 때만 더합니다.
